# MindStrike Academy

MINDSTRIKE — LOVABLE MASTER BUILD PROMPT

Build MindStrike, a playful AI-powered educational gaming platform for children.

Core idea

MindStrike turns learning into interactive games instead of traditional quizzes.

The platform combines:

Education + Mini Games + Physics + Skill + Progression + AI Personalization

The experience should feel closer to a polished children's game platform than a school LMS.

Tagline: “Play. Think. Learn.”

IMPORTANT DESIGN DIRECTION

Do NOT use glassmorphism.

Do NOT create a generic SaaS dashboard.

Do NOT make it look corporate, overly technical, or like a school management application.

Create a warm, colorful, friendly, playful game universe designed for children.

Think:

Friendly cartoon games

Bright illustrated worlds

Soft 2D shapes

Playful characters

Rounded buttons

Large touch-friendly controls

Fun illustrations

Expressive animations

Cheerful sound feedback

Clear typography

Small delightful surprises

Use a consistent visual identity across the platform while giving every game its own personality.

MAIN APP STRUCTURE

Create these major sections:

Home

Game World / Level Map

Carrom Learning Game

Mini Player

AI Learning Analysis

Profile & Achievements

Rewards

Daily Challenge

Navigation should be extremely simple.

Children should understand where to go without reading lengthy instructions.

MAIN CARROM GAME

The main MindStrike game is a digital educational carrom experience.

Create a beautiful physical-looking illustrated carrom board.

Avoid generic UI panels around the board.

The BOARD should be the hero.

Use:

Wooden textures

Colorful illustrated corners

Friendly themed pockets

Playful numbered coins

Soft shadows

Subtle depth

Beautiful lighting

Four category pockets:

🔵 PRIME

🟢 EVEN

🟠 ODD

🟣 COMPOSITE

The categories should look physically integrated into the board.

CARROM AIMING

Make the game extremely approachable.

The player should NOT need professional carrom skills.

Implement:

Drag-to-aim

Power indicator

Accurate trajectory prediction

Rebound prediction

Beginner aim assist

Normal aim mode

Expert mode

Default to Beginner.

The player should feel:

“I can do this!”

while still allowing advanced players to master precision.

CHILD-FRIENDLY UX

Design for children first.

Use:

Large buttons

Simple language

Strong visual hierarchy

Clear icons

Short instructions

Large touch targets

Friendly feedback

Minimal text during gameplay

Never punish mistakes harshly.

The tone should always encourage:

Try → Learn → Improve → Celebrate

RESPONSIVENESS

The platform must work beautifully on:

Desktop

Tablet

Mobile

Prioritize touch interaction.

Mini-games should feel natural on touch screens.

PERFORMANCE

Keep animations smooth.

Target approximately:

60 FPS

Avoid excessive particles and heavy effects.

Use lightweight animations where possible.

IMPORTANT PRODUCT PRINCIPLE

MindStrike should NOT feel like:

“An educational website containing games.”

It should feel like:

“A game universe where children happen to learn.”

The child should open the platform because it is fun.

Learning should naturally happen through play.
